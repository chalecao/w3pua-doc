    GitHub Proxy

    #GitHub Proxy

    Convert GitHub links to multiple accelerated channels, solving the problem of slow or inaccessible access to GitHub in some regions. Supports git clone, wget / curl, and raw link modes.

    🔗 GitHub Link

    🚀Accelerated Links

    📍 cloudflare (v4)Primary host, global high-speed distribution. For China mainland and IPv6 networks, please use the optimized servers.
    git clone https://gh-proxy.org/https://github.com/ConardLi/garden-skills.git
    📍 Cloudflare (v4)👍 RecommendedOptimized server, IPv4-only with intelligent DNS resolution.
    git clone https://v4.gh-proxy.org/https://github.com/ConardLi/garden-skills.git
    📍 Cloudflare (v4/v6)Optimized server, supports IPv6/IPv4 intelligent DNS resolution.
    git clone https://v6.gh-proxy.org/https://github.com/ConardLi/garden-skills.git
    📍 Fastly (v4)Fastly CDN node acceleration.
    git clone https://cdn.gh-proxy.org/https://github.com/ConardLi/garden-skills.git
    ℹ️If any sub-acceleration node becomes unavailable, requests will automatically redirect to the primary accelerator within 15 minutes.
